# Advanced Data types 
# The 4 built-in Collections in Python

1. list: List are ordered sequences that allow you to add, remove, or change items after creation, they are indexed starting at 0 and can hold mixed data types like numbers, strings, and other lists

2. Tuples: Tuples are ordered sequences just like lists except that they are immutable and cannot be modified once defined. they are often used for fixed data collections and require a trailing comma for single-item tuples like ("item",).

3. Sets: sets are unordered collections of unuqiue elements, becaude they automatically drop duplicate values and lack an index, they are ideal for membership testing and mathematical operations like unions and intersections

4. Dictionaries: Dictionaries store fdata as key value pairs where every key must be unique and hashable, they allow fast lookups by key rather than numerical position and preserver insertion order in modern python
